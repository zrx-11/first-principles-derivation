# first-principles-derivation

把复杂知识做成能让初中生从零学起、最终能独立推导全部公式的交互式 HTML。

## 这解决什么问题

大部分教学材料默认读者已经会了前置知识。SVM 的讲义直接从"最大间隔"开始，Transformer 的教程直接从 QK^T 开始，数学分析的教材默认读者会雅可比行列式。中间那些"默认你会"的部分，对基础弱的人就是断崖。

这个技能换了顺序：先把目标知识的依赖链一路逆推到初中数学和日常常识，再从根往上逐层推导，每一层补定义、类比、完整代数过程和数值例子。然后用一个"初二、数学中等偏下、需要掰碎了喂"的虚拟学生身份通读产物，凡是读不懂的地方都补上，反复迭代。

## 安装

把本目录复制到技能库：

```bash
cp -r first-principles-derivation ~/.doubao/agent_mode/workspace/.user_skills/doubao-first-principles-derivation
```

目录名要和 SKILL.md 里 `name` 字段一致，否则加载时对不上。

## 触发方式

在对话里说下面这类话会自动命中：

- "教我支持向量机，从零开始推导"
- "把这段课件做成能一步步学的网页"
- "让初中生也能看懂 Transformer"
- "原理讲透，不要跳步"

只说"讲讲某某"不会触发，那是普通讲解，不需要这一整套流程。

## 产物长什么样

单文件 HTML，断网也能打开。KaTeX 的 CSS、JS 和字体全部内联（外部 CDN 在国内经常加载失败，公式会显示成 LaTeX 源码）。

页面结构：知识树总览在前，可点击跳转；每章有生活类比（绿色提示框）、折叠的完整推导、数值例子、前置和后续知识标注；顶部有常驻目录入口和前后章节按钮，桌面端是常驻侧边栏；支持深浅主题；关键概念配 Canvas 交互演示。

## 检查脚本

```bash
python3 scripts/check_render.py 你的产物.html
```

做两类检查。静态扫描找公式里裸写的 `<` 后跟字母，这类写法会被 HTML 解析器拆坏 DOM，导致公式渲染不全，是最常见的故障来源。浏览器检查逐章节统计 KaTeX 元素和残留 `$`，核对导航容器，看移动端视口有没有横向溢出。有 playwright 才跑第二项。

## 设计取舍

**公式全内联，产物变大。** KaTeX 0.16.9 的二十个 woff2 字体约 250KB，内联后 HTML 增重约 340KB。换来的是断网可用、不依赖 CDN、任何设备打开都一样。

**内容按章节拆分，用脚本合并。** 产物超过三四百 KB 后单次写入容易截断，所以骨架和章节分开写，合并脚本负责拼装并做幂等处理。改内容只动章节文件，重跑合并脚本。

**类比先行，定义在后。** 先给画面再给严格定义，比反过来更容易被基础弱的读者接住。类比必须和数学关系严格对应，只是"感觉像"的不收。

**教材例子不轻信。** 实际遇到教材例题的验证点代进去不满足方程。所有数值例子自己算一遍，不通就换自拟题并在正文注明。

## 已知限制

必须是单文件 HTML。用户要 PPT、Word、在线文档时这套流程不适用，应该是别的产物。

交互演示用 Canvas 手写，复杂的三维演示要另外接 three.js，步骤会更长。

截图自检依赖 shot.py，其中 `--eval` 在 chrome CLI 分支会被静默跳过。交互状态的验证要靠静态审查，不要指望 eval 结果。

## 三个已交付的产物

支持向量机（十五章节，六个 Canvas 演示）、Transformer（含独立数学基础章节）、数学分析 18-20 章（十一个章节，三个坐标系变换）。三次都经历了六轮左右的卡点迭代，补出来的前置知识清单记在 `references/workflow.md` 里，下次遇到同类课题可以直接复用。
